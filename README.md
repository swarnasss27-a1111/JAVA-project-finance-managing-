# Finance Tracker (Java Console Application)

A simple and effective **personal finance tracker** built using Java.  
This application helps users manage their daily income and expenses, view balance, analyze spending categories, and maintain a history of all transactions — all through a clean and interactive console interface.

---

## 🚀 Project Overview

The Finance Tracker allows users to record **income** and **expenses**, view all transactions, track remaining balance, and filter spending by category.  
It is designed using Object-Oriented Programming (OOP) concepts and stores all data in memory without requiring a database.

This project is perfect for students learning Java, beginners practicing OOP, and anyone wanting a simple budget-tracking system.

---

## ✨ Features

### ✔ Add Income  
- Enter amount  
- Choose category (Salary, Bonus, Gift, etc.)  
- Optional description  
- Automatically updates balance  

### ✔ Add Expense  
- Checks if balance is sufficient  
- Enter amount, category & description  
- Automatically reduces balance  

### ✔ View Current Balance  
Displays the remaining balance after all income/expenses.

### ✔ View All Transactions  
Shows:
- Type (Income/Expense)  
- Category  
- Amount  
- Date & time  
- Description  

### ✔ Filter by Category  
View spending patterns by filtering:
- Food  
- Travel  
- Rent  
- Shopping  
- Salary  
- etc.

### ✔ Exit  
Closes the application safely.
